For authorised committee editors

Manage website content

Add approved event details, newsletters, stories, sponsor profiles and photo albums through a guided editing screen.

First-time setup

Connect the editor to GitHub

  1. Open Pages CMS and sign in with the GitHub account that owns this website repository.
  2. Install the official Pages CMS GitHub App for the repository basavasamithibrisbanebsoa/basavasamithibrisbane-website.
  3. Choose the main branch, then open the content collections.
  4. Save an approved change. GitHub Pages will deploy the updated public site from the repository.
What editors can add

Content collections

  • Events: date, time, venue, description and a registration link.
  • Photo albums: upload images, add captions and group them by activity.
  • Newsletters: upload a PDF and list its issue date and description.
  • Stories: publish a title, summary, full text and optional cover photo.
  • Sponsors: add an approved profile, logo and website.
  • Office bearers: update portrait photos while retaining the current names and roles.

Publishing and privacy

Saving through Pages CMS writes files to the public GitHub repository and triggers the existing website deployment. Anything published here can be viewed or downloaded by anyone.

Only publish content approved by the committee. Get permission before posting identifiable photos, sponsor logos or member stories. Do not upload membership applications, personal contact lists, bank details or payment credentials.

Online payments, membership records and private member-only content need a separate secure service. The public website does not collect or store those details.
