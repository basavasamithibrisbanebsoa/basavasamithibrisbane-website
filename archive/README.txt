Basava Samithi Brisbane website archive
Created: 20 November 2026 (Brisbane time)

OVERVIEW
The live domain basavasamithibrisbane.org currently serves a GoDaddy parking page. Its current sitemap lists only /lander. Historical copies are available in the Internet Archive, and this folder preserves the accessible material for rebuilding the site.

WHAT WAS SAVED
- 122 of 122 HTML page captures listed by the Wayback CDX index.
- 207 other files, including images, stylesheets, scripts, logos, fonts, favicons, and sitemap files.
- 6 PNG appearance screenshots in screenshots\.
- 329 of 340 unique archived URLs were downloaded successfully. The remaining 11 are supporting assets, listed as failed in download_log.csv.

FOLDER GUIDE
- site_files\ : downloaded page captures and assets. Directory pages use index.html where possible.
- screenshots\ : PNG captures of representative archived pages. Wayback's archive toolbar is visible in each screenshot. Some snapshots have missing historical styles or images.
- inventory.csv : original URL, capture timestamp, media type, and other CDX details for all 340 indexed URLs.
- download_log.csv : download outcome and local path for every URL. Rows marked failed could not be retrieved during this archive run.
- archive_index.json : raw Internet Archive CDX response used to build this archive.

HISTORY INCLUDED
The index contains the earlier PHP site (2017-2018) and later versions with About, Pages, People, Blog, Posts, Events, Sponsors, committee information, and site assets (2021-2026). The page files are archived captures, not a ready-to-host website. Some links still reference the original domain or Wayback, and the original PHP back end and forms are not included. Use the URL-to-file mapping in download_log.csv when rebuilding.
